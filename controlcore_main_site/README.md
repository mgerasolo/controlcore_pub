## 🧠 Key Features

- Live MQTT integration with control topics
- Sensor data polling at 3-second intervals
- Quick control of irrigation valves (e.g., Open/Close commands)
- Status panels for controller and sensors
- Integration-ready for TimescaleDB, OpenWeather data, and more
